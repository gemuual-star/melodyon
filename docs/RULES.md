# Правила проекта Melodyon (действуют на весь проект)

Доступы (github_token, данные Google Drive) хранятся ТОЛЬКО в песочнице: `/home/user/.secrets/secrets.json`. В git не попадают.

1. GitHub: разработка идёт через него. Работать только с репозиториями, названными в задаче (`gemuual-star/melodyon` — приватный, исходники; `gemuual-star/melodyon-releases` — публичный, только сборки). Остальные репозитории аккаунта не читать, не менять и не удалять.
2. Первым коммитом сохранить эти правила как docs/RULES.md и вести docs/PROGRESS.md: что сделано, текущее состояние, что не проверено, следующие шаги, как восстановить окружение (точные команды, версии, пути).
3. Песочница может обнулиться в любой момент. Коммитить и отправлять на GitHub после каждого логического куска и обязательно перед долгими операциями (сборка, полный прогон тестов). Незавершённое помечать в сообщении коммита как WIP.
4. Клонировать заново только если песочница оказалась пустой. Тогда клонировать репозиторий, прочитать docs/RULES.md и docs/PROGRESS.md, восстановить окружение и продолжать с того же места, не спрашивая владельца.
5. Историю не переписывать, force push не делать, ветки и теги не удалять без просьбы владельца.
6. Google Drive: только для того, чему не место в git (готовые сборки, большие файлы). Работать только внутри папки folder_id, в подпапке с именем проекта (Melodyon). За её пределами ничего не читать, не создавать и не удалять. При обновлении файла заменять содержимое, новый не создавать.
7. Секреты: токены и ключи подписи хранить только в песочнице. Не коммитить, не класть на Drive, не выводить в логи, не записывать токен в адрес remote. .gitignore для секретов, сборочных каталогов и кэшей.
   Исключение, согласованное с владельцем: ключ подписи Android дополнительно хранится как зашифрованный секрет GitHub Actions в приватном репо (не в git).
8. Перед тем как назвать шаг готовым — прогонять тесты и сборку. Новый код покрывать тестами.
9. В отчёте: что сделано, сколько тестов прошло, что не проверено, что не сделано, последний коммит на GitHub. Не называть готовым непроверенное. Если сделано не всё — сказать в первой строке.
10. Если GitHub отклонит токен — остановиться и сообщить. Если токен отклонит Google — дать ссылку для повторного входа с client_id (redirect_uri http://localhost, scope drive, access_type=offline, prompt=consent).
11. Если в задаче чего-то не хватает — задать вопросы до написания кода.

## Задача
Форк последней версии Metrolist (v14.0.1, https://github.com/metrolistgroup/metrolist) в приватный репо, собственная сборка под Android и Windows:
1. Все названия «metrolist» → «melodyon»; конкретные ссылки и контакты убрать. Упоминание Metrolist в UI убрать полностью (решение владельца).
2. Обновления — не с источников Metrolist, а из `gemuual-star/melodyon-releases`.
3. SoundCloud как альтернативный источник треков без авторизации; вызов только по таблетке первой в ряду фильтров поиска (перед All/Songs/Videos...). Полная поддержка: тексты (через встроенные провайдеры), скачивание, очередь, локальные плейлисты и т.д.
